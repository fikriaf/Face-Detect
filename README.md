# Face-Detect

This project demonstrates real-time face detection from video streams using OpenCV and the Haar Cascade Classifier.
It captures video from a webcam and identifies human faces within the frames.

## Features

- Real-time face detection using webcam input.
- Utilizes OpenCV's Haar Cascade Classifier for face detection.
- Simple and easy-to-understand implementation in Python.

## Requirements

- Python 3.x
- OpenCV (cv2)

## Installation

1. Clone this repository:

   ```bash
   git clone https://github.com/fikriaf/Face-Detect.git
   cd Face-Detect
   ```

2. Install the required dependencies:

   ```bash
   pip install opencv-python
   ```

## Usage

1. Ensure your webcam is connected and functioning.
2. Run the main script:

   ```bash
   python main.py
   ```

3. A window will open displaying the video feed with detected faces highlighted.
4. Press the `Esc` key to exit the application.
